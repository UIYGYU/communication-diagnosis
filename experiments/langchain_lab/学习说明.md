# LangChain 入门支线学习目录

先阅读[支线学习顺序](<../../../文档/开发教程/支线学习顺序.md>)，再按[LangChain 入门支线教程](<../../../文档/开发教程/LangChain 入门支线教程.md>)编写本目录的 `demo.py`，复制并阅读 `test_demo.py`。完整实现见[配套参考](<../../../文档/开发教程/配套参考/LangChain支线/>)。

终端从代码项目根目录 `E:\python workspace\network diagnostic assistant\communication-diagnosis` 运行；模型配置继续使用本机 `.env` 中的三个 `LLM_*` 值。

这次只认识模型适配、`@tool`、`create_agent()` 与消息列表。工具直接复用首版的本地 `CaseTools`。完成一次真实工具调用与结果回传后，再进入相邻的 `experiments/langgraph_lab`，学习显式状态、条件边、会话与 MCP 连接。

DeepSeek Harness 作为并行的架构阅读支线；正式第二版之后仍在同一条 `src` 主线推进。
