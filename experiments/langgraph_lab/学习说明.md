# LangGraph 支线学习目录

本目录用于对照首版手写 Agent 与 LangGraph。完整教程见[LangGraph 支线开发教程](<../../../文档/开发教程/支线/LangGraph 支线开发教程.md>)；完整代码见[配套参考](<../../../文档/开发教程/配套参考/LangGraph支线/>)。

先看[支线学习导航](<../../../文档/开发教程/支线/学习导航.md>)：建议完成 LangChain 的模型、工具和消息小入门后，再做本目录的编排对照，不要求先学完整个 LangChain 生态。

代码项目根目录是 `E:\python workspace\network diagnostic assistant\communication-diagnosis`。终端从该根目录运行，Python 继续使用项目的 3.13 环境。

按教程依次在本目录编写：

| 文件 | 学习目标 |
| --- | --- |
| `basics.py` | 状态、节点、边、编译与执行的短练习 |
| `graph_agent.py` | 将模型请求、工具执行、报告校验拆为真实图节点 |
| `demo.py` | 真实模型与 MCP 入口、同线程追问、每问重建工具连接 |
| `test_graph.py` | 图回路、历史、引用、预算与线程隔离的离线测试 |
| `test_demo.py` | 终端入口的真实 MCP 重连与资源清理测试 |

首版 `examples/stage1` 至 `examples/stage4` 继续保留；正式二版已选定 LangGraph；本目录保留作对照，后续从[第二版学习导航](../../../文档/开发教程/第二版/学习导航.md)逐段编写 `src` 主线。依赖安装和模型配置按教程操作；这里没有放置密钥或自动发起模型请求的启动逻辑。
